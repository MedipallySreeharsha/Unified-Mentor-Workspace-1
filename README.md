# Unified Mentor Workspace 1

## Module 1: Vectors using NumPy

This repository contains the completed Jupyter Notebook worksheet for
**Module 1** of the Unified Mentor workspace.

### Notebook

-   [`Module_1_worksheet.ipynb`](Module_1_worksheet.ipynb) --- exercises
    covering NumPy arrays and vector operations.

### Topics Covered

-   Creating NumPy arrays
-   Vector addition and subtraction
-   Scalar multiplication
-   Element-wise multiplication
-   Vector and matrix multiplication
-   Transpose and dot product
-   Matrix inverse and identity matrix
-   NumPy universal functions (ufuncs)

### Requirements

-   Python 3
-   Jupyter Notebook
-   NumPy

### Run the Notebook

1.  Clone or download this repository.

2.  Open a terminal in the repository folder.

3.  Install the dependencies:

    ``` bash
    pip install numpy notebook
    ```

4.  Start Jupyter:

    ``` bash
    jupyter notebook
    ```

5.  Open `Module_1_worksheet.ipynb` and run the cells.
